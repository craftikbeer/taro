# Магия Чисел - Нумерологический Сайт

## Описание проекта
Профессиональный сайт о нумерологии с калькулятором совместимости в стиле дизайна Артемия Лебедева: минимализм, чёткая типографика, чёрные рамки и продуманная цветовая палитра.

## Основные функции
- **Полный нумерологический расчет**: Глубокий анализ личности с расчетом всех чисел (Жизненного Пути, Души, Личности, Судьбы, Зрелости), матрицы Пифагора, кармических долгов и практическими рекомендациями
- **Калькулятор совместимости**: Расчет нумерологической совместимости двух людей с AI-анализом
- **Счастливые числа**: Персональный расчет счастливых чисел
- **Годовой календарь**: Прогноз энергетики каждого месяца
- **Информация о нумерологии**: Объяснение основных концепций

## Технологии
- React 18
- TailwindCSS
- Lucide Icons
- Groq AI API

## Структура
- `index.html` - главная страница
- `app.js` - основное приложение
- `components/` - React компоненты (Header, Hero, CompatibilityCalculator, PersonalNumerology, LuckyNumbers, YearlyCalendar, NumerologyInfo, Footer, ShareButtons)
- `utils/` - утилиты для расчетов нумерологии и AI-анализа

## Дизайн
**Стиль**: Артемий Лебедев - минимализм, функциональность, чёткость

**Цветовая схема**:
- Основной красный: #CC0000 (благородный оттенок)
- Hover: #990000
- Текст: #000000 / #666666
- Рамки: #000000 / #CCCCCC
- Фон: #FFFFFF / #F5F5F5

**Типографика**:
- Меньше CAPS LOCK, больше сдержанности
- Чёткая иерархия размеров
- Точный spacing и ритм

**Интерактивность**:
- Плавные hover-эффекты на карточках
- Анимированные подчёркивания в навигации
- Микроанимации кнопок
- Липкий header

**Контент**:
- Конкретные факты вместо маркетинговых фраз
- 12 чисел в анализе, 3 нумерологические системы, AI-анализ
- Профессиональный тон без лишнего пафоса
